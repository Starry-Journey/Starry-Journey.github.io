## 这里是什么

一个记录思考、拓展视野的个人站点，顺便把一些想法做成可以玩的小东西。

- **博客**：生活、阅读与思考
- **每日简报**：每天自动抓取、打分、翻译的外网资讯，按科技 / 开源工具 / 创意艺术 / 经济商业 / 科学 / 生活文化分类
- **太阳系地图**：2D 俯视 + 3D 视角，真实轨道、时间轴、任务档案和故事线
- **评论区与 AI 助手**：自建聊天室后端 + DeepSeek 驱动的大肥鱼

## 技术栈

Hexo 7 + Stellar 主题，GitHub Actions 构建并发布到 GitHub Pages；
服务端是 Ubuntu + systemd + nginx，评论与 AI 助手跑在自己的 VPS 上。
